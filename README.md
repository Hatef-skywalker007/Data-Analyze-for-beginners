# Data Analysis for Beginners

This repository contains a beginner-friendly data analysis project using the `vgsales.csv` video game sales dataset.

## Project Overview
- Dataset: `vgsales.csv`
- Main analysis notebook: `GSProject.ipynb`
- Goal: Explore video game sales trends and derive basic insights for beginners learning data analysis.

## What is included
- Exploratory data analysis on video game sales
- Data cleaning and summary statistics
- Visualizations and insights for top-selling platforms, publishers, and regions
- Beginner-friendly Python code and markdown explanations in `GSProject.ipynb`

## How to use
1. Open `GSProject.ipynb` in Jupyter Notebook or JupyterLab.
2. Run the notebook cells from top to bottom.
3. Review the charts and analysis for sales performance and distribution.
